# Audit — 2026-09-25: Break-It Pass + Motion Layer

> What was tried, what broke, what was fixed, and what still needs a decision. Branch `feat/motion-audit`. Later the same day the Astro docs site was replaced by the visual workbench (`apps/workbench`) — see the decisions log.

## How the components were attacked

Six parallel QA passes, one per component group, each trying to break every component with: extreme content (long unbroken strings, emoji, RTL, empty), extreme numbers (0, negative, NaN, huge, non-integer cents, JPY/KWD), prop combinations (controlled ↔ uncontrolled, disabled + error), interaction abuse (double clicks, rapid toggles, keyboard-only, IME composition), 320px–1440px layouts, dark mode, Windows High Contrast (forced colors), SSR/hydration, and timer/listener leaks. Every real bug got a regression test. Then a real-browser sweep: all 73 docs pages × 5 widths (320/375/768/1024/1440) × light/dark, measuring horizontal overflow, text spilling out of boxes, console errors, and axe accessibility violations.

**Totals:** ~164 bugs fixed across 58 components. Tests 1,036 → 1,177. Lint, typecheck (all packages, incl. Storybook and docs) green.

## Worst bugs found (by severity)

**Broken for everyone**
- PredictiveSearch fired its search in an infinite loop with an inline `onSearch` (the documented usage).
- Countdown crashed hydration (time computed during render) — the whole island re-rendered on the client.
- Enter in PredictiveSearch blocked the surrounding form from submitting.
- Toasts past `maxToasts` came back from the dead with fresh timers.
- Carousel dropped rapid Next clicks; gallery disappeared entirely when a variant switch shrank the image list.
- CartLineItem built prices by hand: "$4800.00", "$-5.00", and $ beside a € subtotal. CartDrawer didn't pass its currency down.
- `<Button>` inside a `<form>` submitted it (no default `type`).
- Pages rendered `<Heading level={1}>` (not a prop) → `<h2 level="1">`, no h1 on two pages. Uncaught because docs typecheck (`astro check`) was never installed.

**Broken for keyboard / screen reader / high-contrast users**
- Focus ring invisible (1.4:1) on ~50 components; and box-shadow-only rings vanish entirely in Windows High Contrast. Fixed at the token + transparent outline.
- Loading buttons used native `disabled`, throwing focus to `<body>` for the whole add-to-cart cycle.
- Error messages not linked (`aria-describedby` pointed at unrendered hint ids) in six form components; Select hints/errors never announced.
- Select had no way to be named without a visible label (axe critical on four example pages).
- Stepper labels `display:none` on mobile → steps had no names.
- StarRating review count never read (hidden inside `role="img"`); "NaN out of 5 stars".
- Checkbox indeterminate, Radio dot, Switch, Slider, SegmentedControl selection, ProgressBar fill all disappeared in forced-colors mode.
- Escape inside PredictiveSearch in a Modal closed the whole Modal.

**Broken on phones**
- 12 nav links made the page 1210px wide at 768px; hamburger squeezed to 20px at 320px; drawer stayed open (scroll-locked) after rotating to desktop width.
- Breadcrumb/Pagination/Tag/Button/Typography overflowed at 320px; long words blew out grid columns (`1fr` → `minmax(0,1fr)`).
- iOS zoom-on-focus in PredictiveSearch (font < 16px on touch).
- CookieConsent grew past the top of short screens; Modal close button scrolled out of view on long content; Drawer close button under the notch.
- Popover/DropdownMenu/Select opened *behind* Modals and Drawers (z-index).

## Open — needs a decision

1. **Optical centering never ran.** `text-box-trim: both` is invalid CSS (56 declarations); fallback nudge runs everywhere; valid trim needs a label span on flex roots. One deliberate pass + visual re-baseline. See `07-lessons-learned.md#text-box-trim-invalid`. CLAUDE.md carries the same wrong snippet.
2. **Long button labels at 320px** overflow (350px button in a 288px column). Two-line wrap inside the fixed height vs. ellipsis — changes flex behavior in ~9 consumers.
3. **Dark mode has no elevation** (surface = subtle; black shadows invisible).
4. **Badge status variants are all live regions** (`role="status"`) — every "Out of stock" in a grid announces. Make opt-in.
5. **Toast live regions** are inserted with text already inside; NVDA/VoiceOver often skip them. Needs persistent polite/assertive regions in ToastProvider.
6. ~~**Footer grid** fits 3 columns; 4–6 wrap under the brand block at ≥768px.~~ **Resolved (visual pass):** Footer uses the 12-column grid from 1024px; 5–6 columns put the brand on its own row.
7. ~~**Fonts** are a render-blocking cross-origin stylesheet; self-host a Latin subset with a metric-matched fallback.~~ **Resolved 2026-10-07** for the storefront (self-hosted, preloaded) and for both repos' tokens (metric-matched stand-ins, measures in em). The workbench still uses Google Fonts.
8. **Storefront (Liquid) repo** needs porting: tokens re-sync, focus ring, border-control, VariantSelector label, QuantitySelector overflow, ColorPicker ring, Breadcrumb label span, Footer h2, Accordion heading levels, Tabs divider, StarRating label, CollectionFilters pill text, and `@ds/motion` (needs a browser ESM build for the theme's flat assets folder).
